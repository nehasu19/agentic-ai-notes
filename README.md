
# Agentic AI Playbook
to start learning click on link https://nehasu19.github.io/agentic-ai-playbook/

My personal notes on how AI agents work and how organizations can use them well.
Everything here is written in my own words, from my own study and practice.

## What's here

- `index.html` and `data.js` — the topics: learning goals, key ideas, a deeper dive with a diagram, a test and a glossary.
- `assignments.html` — the 8 practice projects: what each asks for and what to cover.
- `references.html` and `references.js` — the full reading list: public sources by topic, with search.
- `tokens.js` — the token counter on topic 2 (loads the open-source gpt-tokenizer from jsDelivr; falls back to an estimate offline).
- `diagrams.js`, `quiz.js` — topic diagrams and self-tests.
- `lessons.js` — guided lessons (topic 1 so far): topic overview, one idea per lesson, real examples with sources.
- `style.css`, `tokens.css`, `base.css` — shared styles (teal and amber theme, light and dark).

## Publish on GitHub Pages

1. Create a new repository on GitHub.
2. Upload these files (or `git init`, `git add .`, `git commit`, `git push`).
3. In the repo go to **Settings → Pages**, set **Source** to "Deploy from a branch",
   pick `main` and `/ (root)`, then save.
4. Your site appears at `https://<your-username>.github.io/<repo-name>/` within a minute or two.

## Editing

Topic text lives in `data.js`, lessons in `lessons.js`, test questions in `quiz.js` and
projects in `assignments.html`. Edit those files and refresh the page.
